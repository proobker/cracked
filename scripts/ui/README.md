# User interface

| File | Current responsibility |
|---|---|
| menu.gd | Title/plaza backdrop, play/practice/settings, Play Games status |
| level_select.gd | Campaign selection and progress presentation |
| hud.gd | Combat info, markers, banners, hurt/combo feedback |
| crosshair.gd | Crosshair/spread |
| touch_controls.gd | Touch movement, look, fire and buttons |
| settings_panel.gd | Adjustable settings |
| armory.gd | Persistent purchases, loadout, active build and separate practice preview |
| skill_tree.gd | 405-node icon canvas, pan/zoom, picking, hover and keyboard navigation |

Interfaces are built in GDScript. UI presents state and requests actions;
services validate purchases and own persistence.

## Armory and combat UI

Campaign discovery uses SkillCatalog.is_revealed: sufficient player level and
one purchased parent, independent of coins or active slots. SkillTree rebuilds
its draw/pick map from those nodes; hidden endpoints never draw connections.
FIT frames the revealed map. Practice's complete ownership reveals all nodes.

Armory opens from menu/level select: connected 405-node tree, XP/player level, banked
coins, ranks/costs/effects, alternative paths, slots, capstone limit and loadout.
Tier-locked nodes are dimmed. Each node draws its effect's SVG icon
(assets/skills, generated by tools/generate_skill_icons.py): plates for the 39
skills, circles for echoes, a ring for capstones. Hover and the inspector lead
with name and meaning; exact tuning follows in small text. Save IDs never show.
The practice toggle only works when opened from Practice Range; elsewhere it
stays off and shows a non-blocking notice.
level_map.gd draws the galaxy: one star per level, scattered along spiral arms,
with a zoom-out-then-in flight between stars. conquered.gd is the ending
after the finale; ui_icons.gd builds the icon-only buttons (assets/ui).
Purchasing and activation require separate explicit buttons. Wheel, pinch and
buttons zoom; drag pans; FIT shows all nodes. Arrows navigate, Enter inspects,
F fits, +/- zoom. Branch buttons focus foundations without hiding other branches.
Normal effects aggregate to a maximum of three rank-equivalents; slots expand
4/8/14/24 at levels 1/5/15/25. Only one capstone can be active.

HUD separates unbanked coins from banked money and displays grenade charges.
Clear feedback confirms committed rewards; failed saves/purchases show retry
feedback. Builds change only between attempts.

## Checks

Real-phone tree readability, long labels, alternate prerequisite highlighting,
invalid purchases, dependent deactivation, preview cancellation and overlays
without click-through into gameplay.
